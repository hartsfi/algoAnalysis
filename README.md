## Goal
The goal of this repo is to graph, analyze, and discuss the following algorithms:
- Insertion Sort
- Randomized Quicksort
- Stable Counting Sort

## Language
The language of implementation is Python, my running version is 3.14.3 (Though it may work with more current versions too)

## Requirements.txt
Please run "pip install -r requirements.txt" before trying to run anything, this will install all requirements

## How to run
You can run this by typing into your terminal "python main.py" assuming you're in a directory that hosts all of these files

## Algorithms.py
This file will house all three of the algorithm implementations

## Testing.py
This file will house the testing for the three algorithms:
- Time my implementation against the library implementation against n = [10,100,1000,10000,...]

## Graphing.py
This file will house the graphing and displaying of the algorithms when tested against n

## main.py
Put the three files together in order to get a cohesive result that flows well
